For men: ht=(2.02 X knee height) - (0.04 X age)+64.19
For women: ht=(1.83 X knee height) - (0.24 X age)+84.88

For men: Wlo = ht - 100 -((H-150)/4)
For women: Wlo = ht - 100 -((H-150)/2.5)

GNRI = ( (albumin X 1.489) + (41.7 X measured weight/Wlo)
Wlo = Calculated Ideal Body Weight (Lorentz Formula)
