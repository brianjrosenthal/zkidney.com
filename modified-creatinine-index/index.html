The Formula:
Modified Creatinine Index (mg/kg/day)=16.21 +(1.12X[1 if male; 0 if female]) -(0.06 X age(years)-(0.08 X SP Kt/V urea) +(0.009 X serum creatinine before dialysis (mg/dL)
